🎯 Content Objective
"I can calculate the total surface area of a 3D triangular prism by unfolding it into a 2D net and adding all 5 face areas together."
📐 Visual Representation: Student laying flat the 3D prism into a 2D net on her desk grid mat to calculate face dimensions.
  • 📐 3D ➔ 2D Net Unfold: Laying out all 5 faces flat so no area calculation gets missed.
  • ✨ Grid Measurement: Base height = 4cm, base = 6cm. Precise area calculations.
  • 💯 Total Surface Area: Summing 2 triangular bases + 3 rectangular faces.
💬 Language Objective
"I can explain my geometry reasoning using academic vocabulary terms like triangular base, rectangular face, and vertex."
🗣️ Visual Representation: Student partners pointing to geometry vocabulary badges and using academic sentence frames.
  • 💬 Academic Speech Frame: "By looking at the 2D net, we can identify all specific parts..."
  • 🏷️ Vocabulary Badges: Direct visual pointers to Triangular Base, Rectangular Face, and Vertex.
  • 🤝 Peer Collaboration: Explaining step-by-step to partner with precise math terms.
🎯 Content Objective
"I can solve one-step algebraic equations (such as x + 3 = 7) by isolating the variable using an interactive balance scale model."
⚖️ Visual Representation: Student actively balancing an algebraic scale with variable blocks to isolate x.
  • ⚖️ Algebra Balance Model: Equalizing weights on left and right scale pans.
  • 🧩 Isolating Variable x: Subtracting equal quantities from both sides.
  • ✅ Solution Verification: Proving $x = 4$ maintains perfect algebraic balance.
💬 Language Objective
"I can describe equation-solving steps using mathematical vocabulary terms like variable, isolate, and inverse operation."
🗣️ Visual Representation: Student partners discussing algebraic balance steps using sentence frames.
  • 💬 Academic Speech Frame: "To isolate the variable x, I applied the inverse operation..."
  • 🏷️ Vocabulary Badges: Labeling Variable x, Isolate, and Inverse Operation.
  • 📝 Written Explanation: Summarizing inverse steps clearly in math notebooks.
